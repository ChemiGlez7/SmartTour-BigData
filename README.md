# SmartTour Big Data

Proyecto académico de análisis Big Data aplicado al turismo.

## Objetivo

Crear una plataforma para analizar datos turísticos.

## Tecnologías

- Python
- Docker
- JupyterLab
- GitHub

## Estructura

datasets:
Datos utilizados en el proyecto.

scripts:
Programas Python.

notebooks:
Análisis realizados.

docs:
Documentación.
